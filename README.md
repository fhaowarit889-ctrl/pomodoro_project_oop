# Pomodoro Focus Timer

## รายละเอียดโครงการ

แอปพลิเคชันจับเวลาแบบ Pomodoro พัฒนาด้วย Python และ PySide6 สำหรับการบริหารเวลาทำงานอย่างมีประสิทธิภาพ รองรับการบันทึกสถิติ แสดงผลแบบกราฟ และหน้าตา User Interface แบบ Glass Morphism ที่ทันสมัย

## ฟีเจอร์หลัก

**ฟังก์ชันจับเวลา**
- โหมดโฟกัส (Focus Time) 25 นาที สำหรับการทำงาน
- โหมดพักสั้น (Short Break) 5 นาที ระหว่างรอบการทำงาน
- โหมดพักยาว (Long Break) 15 นาที เมื่อทำงานครบ 4 รอบ
- ปุ่มควบคุม Start, Pause, Reset และ Skip
- แสดงเวลาแบบเรียลไทม์รูปแบบ MM:SS
- วงกลมแสดงสถานะความก้าวหน้า

**ระบบสถิติและรายงาน**
- บันทึกจำนวน Pomodoro ที่ทำได้ทั้งหมด
- บันทึกเวลาโฟกัสและเวลาพักรวม
- สถิติรายวันและรายสัปดาห์
- กราฟแท่งแสดงแนวโน้มการใช้งานประจำสัปดาห์
- แผนภูมิวงกลมแสดงสัดส่วนเวลาโฟกัสและเวลาพัก
- การนับสถิติการทำติดต่อกัน (Streak)
- ระบบ Achievements สำหรับสร้างแรงจูงใจ

**การออกแบบ UI**
- รูปแบบ Glass Morphism สไตล์โมเดิร์น
- เอฟเฟกต์ Hover และ Animation
- รองรับการแสดงผลความละเอียดสูง
- พื้นหลังแบบ Gradient สีเข้มลดอาการเมื่อยล้าดวงตา

## วิธีการใช้งาน

**การเริ่มต้นใช้งาน**
1. เปิดโปรแกรมจะพบหน้าจอหลักแสดงตัวจับเวลาเริ่มต้น 25 นาที
2. กดปุ่ม START เพื่อเริ่มจับเวลาในโหมดโฟกัส
3. เมื่อครบเวลา 25 นาที โปรแกรมจะแจ้งเตือนและเปลี่ยนโหมดเป็นพักอัตโนมัติ

**การควบคุมโปรแกรม**
- START: เริ่มจับเวลา
- PAUSE: หยุดจับเวลาชั่วคราว
- RESET: รีเซ็ตเวลากลับเป็นค่าเริ่มต้นของโหมดปัจจุบัน
- SKIP: ข้ามโหมดปัจจุบันไปยังโหมดถัดไป

**การดูสถิติ**
1. กดปุ่ม STATS ที่มุมบนซ้ายของหน้าจอ
2. หน้าต่างแดชบอร์ดจะแสดงข้อมูลต่อไปนี้:
   - จำนวน Pomodoro ทั้งหมดที่ทำได้
   - ชั่วโมงโฟกัสสะสม
   - ค่าเฉลี่ยต่อวัน
   - สถิติการทำติดต่อกัน
   - กราฟการใช้งานประจำสัปดาห์
   - แผนภูมิวงกลมแสดงสัดส่วนเวลา
   - Achievements ที่ปลดล็อคแล้ว

**การทำงานของระบบ**
- โปรแกรมจะสลับโหมดอัตโนมัติ: Work -> Break -> Work -> Break -> Work -> Break -> Work -> Long Break
- บันทึกสถิติอัตโนมัติลงในไฟล์ pomodoro_stats.json
- นับจำนวน Pomodoro ที่ทำได้ในแต่ละวัน
- ระบบจะรีเซ็ตสถิติวันใหม่เมื่อเวลาผ่านเที่ยงคืน

## โครงสร้างโครงการ

```
pomodoro_timer.py
├── TimerMode (Abstract Base Class)
│   ├── WorkMode
│   ├── BreakMode
│   └── LongBreakMode
├── StatisticsManager
├── Custom Widgets
│   ├── GlassCard
│   ├── AnimatedProgressBar
│   ├── StatsNumberLabel
│   ├── CircularProgress
│   └── PieChartWidget
├── StatisticsDialog
└── PomodoroTimer (Main Application)
```

**ไฟล์ที่ถูกสร้างขึ้นโดยโปรแกรม**
- pomodoro_stats.json: เก็บข้อมูลสถิติการใช้งาน

## คลาสหลัก

**TimerMode**
คลาสนามธรรมที่เป็นแม่แบบของโหมดจับเวลาทั้งหมด กำหนดคุณสมบัติพื้นฐานเช่น ชื่อ ระยะเวลา สี และไอคอน พร้อมเมธอดที่ต้อง implement ในคลาสลูก

**WorkMode, BreakMode, LongBreakMode**
คลาสลูกของ TimerMode ที่กำหนดรายละเอียดเฉพาะของแต่ละโหมด รวมถึงข้อความแจ้งเตือนและคำแนะนำ

**StatisticsManager**
จัดการการบันทึกและโหลดข้อมูลสถิติ เก็บข้อมูลในรูปแบบ JSON มีเมธอดสำหรับเพิ่มสถิติ คำนวณแนวโน้ม และดึงข้อมูลย้อนหลัง

**StatisticsDialog**
หน้าต่างแสดงแดชบอร์ดสถิติแบบ Popup ใช้ QDialog และ QScrollArea รองรับการแสดงข้อมูลปริมาณมาก

**PomodoroTimer**
คลาสหลักของแอปพลิเคชัน ควบคุม UI ทั้งหมด จัดการการทำงานของ Timer และเชื่อมต่อกับ StatisticsManager

## หมายเหตุเพิ่มเติม

**การปรับแต่ง**
ผู้ใช้งานสามารถปรับระยะเวลาของแต่ละโหมดได้โดยแก้ไขค่า duration ในคลาส WorkMode, BreakMode และ LongBreakMode

**การจัดเก็บข้อมูล**
ไฟล์ pomodoro_stats.json จะถูกสร้างขึ้นในโฟลเดอร์เดียวกับไฟล์โปรแกรม หากต้องการล้างข้อมูลสามารถลบไฟล์นี้ได้

**ข้อจำกัด**
- ระยะเวลาสูงสุดของแต่ละโหมดคือ 120 นาที
- โปรแกรมรองรับเฉพาะการใช้งานแบบ Single user
- ยังไม่มีฟังก์ชันแจ้งเตือนเสียง (อยู่ในแผนพัฒนา)
